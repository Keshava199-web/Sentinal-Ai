# 🛡️ Sentinel-AI
 
### AI-Assisted Security Monitoring Platform
 
Sentinel-AI is a security operations backend built to help analysts track incidents, evidence, indicators of compromise (IOCs), & audit activity through a centralized, RBAC-secured API - with an early-stage dashboard UI on top of it.
 
The backend is built with **Node.js, Express, TypeScript, PostgreSQL (Neon), and Prisma ORM**, following a **Controller-Service-Repository** architecture with JWT authentication, role-based access control, request validation, and audit logging baked in from the start.
 
The long-term goal is to extend this foundation with an AI-assisted triage/summarization layer, real-time event processing, and integrations with common security tooling (SIEM/threat-intel sources) - but this README only claims what is actually built today.
